SparrowFi - Default Categories
================================
These are the categories a brand-new file is seeded with (see
src/app/core/default-categories.ts, which must be kept in sync with this
list if it ever changes). An existing account is topped up to match
automatically whenever it loads - there's no manual "Load Suggested
Categories" step.

Entries marked (Locked) can't be deleted from the Categories page -
StateService looks them up by this exact name to auto-categorize
transactions it generates itself. Fixed Deposits and Investments share
the same three "Investment ..." categories rather than having their own.

Others (Income)
